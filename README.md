# 🚀 PostPilot

> A powerful, full-stack social media automation platform designed to schedule, manage, and optimize your online presence seamlessly.

Built with a high-performance, cutting-edge modern tech stack using **React 19**, **Vite**, **Express 5**, and **Prisma**.

---

## ✨ Features
* ⏳ **Smart Scheduling:** Queue and automate social posts ahead of time.
* 📊 **Interactive Dashboard:** Track analytics, user sessions, and performance metrics.
* ⚡ **Express 5 Core:** Backend engine taking advantage of native async error handling.
* 🎨 **Tailwind CSS v4:** Modern layout styling utilizing optimized native Vite compilers.
* 🗄️ **Type-Safe Database Access:** Fully autogenerated client structures built on top of Prisma ORM.

---

## 🛠️ Tech Stack Architecture

### Frontend
* **Core Framework:** React 19 & TypeScript
* **Build Tooling:** Vite 8
* **State Management:** Redux Toolkit & React-Redux
* **Routing:** React Router DOM v7 (Context-isolated layouts)
* **Styling Framework:** Tailwind CSS v4

### Backend
* **Runtime Environment:** Node.js (TypeScript compiled)
* **Web Framework:** Express 5
* **Database Layer:** Prisma Client v7
* **Development Process:** Nodemon, `ts-node`, and `tsx` hot-reloading execution

## Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# edit .env with your MySQL connection string and JWT secret
npx prisma migrate dev --name init
npm run dev
```

The API runs on `http://localhost:5000/api` by default.

## Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env
# edit .env if your backend runs on a different URL
npm run dev
```

The app runs on `http://localhost:5173`.
